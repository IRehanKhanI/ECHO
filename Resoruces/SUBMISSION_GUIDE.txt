2. PROJECT SUMMARY (copy-paste this — 194 words)
================================================================================

Project ECHO (Earth Correlation & Habitat Observation) is a full-stack
scientific decision-support platform that discovers, qualifies, and permits
terrestrial analog sites for NASA's Artemis IV lunar South Pole surface
campaign (2028).

Artemis IV astronauts will test rovers, drills, and spacesuits on crater rims
where temperatures plunge to -246°C, slopes reach 25°, and abrasive regolith
contains corrosive sulfur. Before flight, engineers must rehearse on Earth —
but existing analog catalogs are static and limited to a handful of well-known
sites.

ECHO solves this through a 6-module pipeline: (1) an interactive 3D Moon globe
built from NASA LRO LOLA/Diviner data, (2) a multi-objective ML matching
engine (R² = 95.10%) that discovered 15 novel unvisited candidate sites across
Antarctica, Chile, and Iceland, (3) deep-dive scientific dossiers, (4) a
Google Gemini AI regulatory permit intelligence system, (5) a 3D digital twin
hardware exposure lab with real sulfur degradation modeling, and (6) an
empirical validation dashboard with PDS-verified cross-validation.

All data is sourced from NASA PDS, Copernicus, ERA5-Land, and PetDB —
zero static placeholders, zero hallucinated permits.

--- WHAT IT DOES & HOW IT WORKS ---

ECHO is a 6-module end-to-end platform for qualifying terrestrial analog
sites for NASA Artemis IV lunar South Pole hardware testing:

Module 1 — Mission Brief: Interactive 3D WebGL globe of the lunar South Pole
(80°S–90°S) rendered from NASA LRO LOLA 240m altimetry and Diviner thermal
radiometry. Users select from 4 verified Artemis IV candidate landing sites
(Shackleton Rim, Malapert Massif, Haworth PSR, Connecting Ridge) with
real-time grazing sun angle computation (+2.4° to +7.1°).

Module 2 — Discover Sites: A multi-objective machine learning matching engine
compares 8 physical parameters (temperature extrema, slope, sulfur
concentration, plagioclase mineralogy, aridity, elevation, FeO weight percent,
and pyroxene content) between lunar targets and 30 global Earth candidate
sites. The engine uses a Random Forest regressor trained on NASA PDS and
Copernicus data with 5-fold spatial block cross-validation achieving
R² = 95.10% and RMSE = 0.0315. A "Novel / Unvisited Sites Only" filter
highlights 15 newly identified locations with ZERO documented prior NASA
field usage.

Module 3 — Site Dossier: Deep-dive 4-pillar scientific characterization for
each candidate site, including geological composition, thermal regime, terrain
morphometry, and negative constraint analysis (where the analog breaks down
relative to lunar conditions).

Module 4 — Access & Permits: An AI-powered regulatory permit intelligence
system using Google Gemini 2.5 Flash that identifies all applicable permits,
zoning laws, environmental clearances (NEPA), export controls (ITAR/EAR),
and statutory restrictions (Wolf Amendment P.L. 112-55 §539) for any
candidate site worldwide. All AI-generated permit information is clearly
flagged as advisory vs. verified statutory data.

Module 5 — Exposure Lab: A 3D digital twin hardware simulation environment
where users import NASA CAD models (.glb, .gltf, .obj) of Artemis IV
equipment (TX-DRILL coring mast, Lunar Terrain Vehicle, Regolith Robotic
Arm, Cold-Soak Lander) and simulate sulfur-driven material degradation using
an empirical wear model calibrated against plagioclase abrasion and sulfate
corrosion data.

Module 6 — Validation: An empirical ML validation dashboard showing
actual-vs-predicted scatter plots, residual distribution histograms, 95%
confidence interval envelopes, and 5-model benchmark comparisons — all
powered by real PDS-verified data, not simulated or mock values.

--- BENEFITS & INTENDED IMPACT ---

1. Discovers 15 novel, unvisited Earth analog sites that have never been used
   for NASA field testing — breaking the "legacy site bottleneck" of
   repeatedly relying on Devon Island, Arizona, and Hawaii.
2. Provides mission planners with quantified, auditable analog fidelity scores
   instead of qualitative "looks similar" assessments.
3. Automates the complex multi-jurisdictional statutory permitting process that
   currently takes weeks of manual legal research.
4. Enables hardware engineers to digitally stress-test rover components against
   realistic abrasive regolith chemistry before committing to expensive
   physical field prototypes.
5. All scientific claims carry full provenance citations traceable to NASA PDS4
   product identifiers.

--- TOOLS, LANGUAGES, HARDWARE & SOFTWARE ---

Frontend:
- React 19, TypeScript 7, Vite 8.3
- Three.js 0.187 + @react-three/fiber 9.4 + @react-three/drei 10.7
  (3D WebGL lunar/Earth globes, hardware digital twins)
- Tailwind CSS 4.3 (responsive styling)
- Recharts 3.10 (scientific scatter plots, histograms)
- Lucide React (iconography)
- Motion (Framer Motion animations)

Backend:
- Python 3.14, Django 5.0, Django REST Framework 3.14
- scikit-learn 1.3 (Random Forest, RobustScaler, spatial cross-validation)
- NumPy 1.24, Pandas 2.0 (data processing)
- xarray + h5netcdf (NetCDF4 multidimensional climate data)

AI Integration:
- Google Gemini 2.5 Flash (@google/genai SDK) — regulatory permit analysis

External APIs:
- Open-Meteo Archive API (historical climate verification)
- Copernicus Climate Data Store (CDS) API — ERA5-Land soil temperature
- PetDB (EarthChem/IEDA) — whole-rock geochemical assays

Deployment:
- Vercel (multi-service: Vite frontend + Django backend)
- GitHub (version control, public repository)

--- CREATIVITY ---

ECHO is creative because it:
1. Treats analog selection as a MULTI-OBJECTIVE optimization problem across
   8 coupled physical parameters simultaneously, not a single-variable lookup.
2. Introduces a "Novelty Filter" that deliberately surfaces sites with ZERO
   prior NASA usage — breaking decades of field testing bias toward the same
   handful of well-trodden locations.
3. Combines planetary science, machine learning, 3D hardware simulation, and
   legal regulatory intelligence into a single unified workflow that has never
   existed before as an integrated platform.
4. Uses a 3D digital twin approach where NASA engineers can import their own
   proprietary CAD hardware models and simulate surface exposure conditions.

--- FACTORS CONSIDERED ---

- Accessibility: Full-stack web application accessible via any modern browser
  with no installation, plugin, or registration required.
- Cost: Uses exclusively open/free NASA and ESA datasets; no paid data
  subscriptions. The Gemini API is available on a free tier.
- Energy: Client-side WebGL rendering minimizes server-side computation.
  The ML model runs in milliseconds on standard hardware.
- Scientific Integrity: Every data point carries provenance citations. The
  platform explicitly warns users that Earth analogs CANNOT reproduce lunar
  vacuum, 1/6th gravity, cosmic radiation, or electrostatic regolith levitation.
